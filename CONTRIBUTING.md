# Mitmachen

Beiträge sind willkommen. FunkGateway soll auch für Funker verständlich bleiben, die keine Linux- oder Python-Profis sind.

Bitte bei Änderungen:

1. bestehende Funktionen nicht unnötig komplizierter machen,
2. neue Hardware-Backends sauber von der GUI trennen,
3. sicherheitsrelevante PTT-Funktionen immer mit PTT-AUS als Ausgangszustand bauen,
4. neue Optionen in verständlicher deutscher Sprache erklären,
5. Quellcode dort kommentieren, wo das **Warum** nicht offensichtlich ist.

Pull Requests sollten kurz beschreiben, welche Hardware bzw. welches Linux-System getestet wurde.
