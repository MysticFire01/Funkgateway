- Selbstrücklauf-Schutz mit RX-Längenmessung und Störungsraum-Eskalation
- Schutz für VoIP, Rufzeichenbake, Rogerbeep/CW-K und Schutzansagen frei wählbar
- verlorene echte Funkdurchgänge können per WAV zur Wiederholung aufgefordert werden
- Rufzeichenbake wartet auf freien Kanal; keine Bake-Warteschlange
- alle Einstellungsseiten scrollfähig
- GitHub-Updateprüfung mit SHA256-Prüfung und Vorbereitung in neuem Versionsordner
